# PersonalTelegram Ultra

Адаптивний одnofайловий прототип месенджера українською мовою.

## Як запустити
Відкрий `index.html` у браузері або опублікуй репозиторій через GitHub Pages.

## Що працює
- Список і пошук демо-чатів
- Створення чатів
- Надсилання повідомлень у локальній історії
- Редагування локального профілю
- Світла/темна тема
- Збереження даних у localStorage браузера

## Важливо
Це лише frontend-демо. Повідомлення не надсилаються іншим людям. Для справжнього онлайн-месенджера потрібні сервер, авторизація, база даних і захист даних. Не зберігай у демо конфіденційну інформацію.
